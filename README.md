# Online Psychologist — Muhammad Zubair

Professional online counseling and therapy platform for anxiety, depression, and relationship issues. Serving clients across Pakistan, the Gulf, and internationally.

**Live site:** https://onlinepsychologist.github.io

## About

Built and operated by **Muhammad Zubair**, MS Clinical Psychology (Bahria University, Lahore). This is a production mental-health platform, not a template site — includes SEO infrastructure, structured data, a blog, tools, and continuous deployment to GitHub Pages.

## What's here

- Full multi-page site: home, about, services, contact, books, blog, tools
- SEO: meta tags, Open Graph, canonical URLs, JSON-LD structured data, sitemap, robots.txt, Bing/Alexa verification
- `llms.txt` / `llms-full.txt` — AI-readable site index
- Python scripts for daily SEO/crawl automation

## Role of AI in this project

AI (Claude) is used throughout the build and operations workflow — content generation, SEO metadata, script writing, and site maintenance. This repo is a working example of practical AI-assisted production engineering, integrated with Git for version control and automated deployment.
